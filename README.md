# XML_PI — 添付文書 比較ビューア（試作）

PMDA が公開している医療用医薬品の XML 添付文書を使い、最大 5 品目を横に並べて、
項目（禁忌、用法及び用量、相互作用、副作用 …）ごとに行を揃えて比較表示するアプリの試作です。

> **開発中は個人利用に限ります。** 公開する場合は、事前に PMDA の許諾を得てください。
> 表示内容は XML を本アプリで再構成したものです。正式な内容は各列の「PDF」「PMDA」リンクから確認してください。

## 使い方

1. **品目を選ぶ** — 医薬品名や薬効分類で PMDA を検索し、「追加」で最大 5 品目まで選びます。
2. **XML を取得する** — 「並べて比較」を押すと、選んだ品目の XML を 1 品目ずつ PMDA から取得します。
3. **並べて表示する** — 項目ごとに行が揃った表で表示します。縦スクロールは全品目で同期し、品目名の見出しと項目名は画面に固定されます。
   - 項目名をクリックすると、その行を折りたためます。
   - 「全品目で同じ内容の行を隠す」で、違いのある項目だけを表示できます。
   - 比較画面の URL（`#compare=…`）をブックマークしておくと、同じ組み合わせを後で開けます。
     その間に添付文書が改訂されていた場合は、自動で最新版を取得します。

## 起動方法

PMDA は CORS に対応していないため、ブラウザから直接 XML を取得できません。
同梱の中継サーバー（`server.py`、Python 標準ライブラリのみ）を起動して使います。

### GitHub Codespaces で動かす

1. このリポジトリの **Code → Codespaces → Create codespace on main** を押します。
2. 起動すると `python server.py` が自動で実行され、ポート 8000 がブラウザで開きます。
   開かない場合は、ターミナルで `python server.py` を実行し、「ポート」タブから 8000 を開いてください。

Codespaces の転送ポートは既定で **非公開**（自分の GitHub アカウントでのみアクセス可）です。公開設定に変更しないでください。

### 自分のパソコンで動かす

Python 3.9 以上が必要です。

```bash
python server.py
```

ブラウザで <http://localhost:8000/> を開きます。

## しくみ

```
ブラウザ（public/）  ──  server.py  ──  PMDA
  検索・選択            /api/search     医療用医薬品 情報検索（検索結果画面を JSON に変換）
  XML の表示            /api/doc/{ID}   ResultDataSetXML/{ID}（ZIP を展開して XML を返す）
                        …/fig/{名前}    ZIP 内の図
```

| ファイル | 内容 |
|---|---|
| `server.py` | 静的ファイルの配信と PMDA への中継 |
| `public/app.js` | 画面の制御（検索・選択、取得、比較表示） |
| `public/render.js` | XML を HTML に変換し、項目ごとに切り出す |
| `public/item-master.js` | 項目マスタ（項目番号・項目名称・XML 要素名） |
| `public/effects.js` | 薬効分類の一覧（PMDA 検索画面の選択肢から生成） |

### PMDA への負荷を抑える工夫

- XML を取得するのは、利用者が選んだ品目（最大 5 品目）だけです。
- PMDA へのリクエストはサーバー側で 1 本ずつ順番に送り、最低 1 秒の間隔を空けます（環境変数 `PMDA_MIN_INTERVAL` で変更可）。
- 取得した XML は 30 分、検索結果は 10 分、サーバーのメモリに保持して再利用します。
- 取得したデータをファイルに保存したり、リポジトリに含めたりはしません。

### 最新版の扱い

PMDA は最新版の XML しか返しません（旧版の ID を指定するとエラー画面が返ります）。
保存しておいた ID が古くなっていた場合、サーバーは一般名ごとの一覧ページ（`GeneralList`）から
同じ品目の最新 ID を探して取得し直します。

### 項目マスタ

比較表の行（項目番号・項目名称・並び順）は `public/item-master.js` の項目マスタに従います。
新記載要領では、該当する記載がない項目は省略できますが、項目番号は繰り上げません。
そのため、どの品目でも同じ番号には同じ項目名称が並びます。

- 項目名称と XML 要素名は、日本製薬工業協会「医療用医薬品添付文書情報の電子ファイル作成の手引き（暫定版第1版）」
  4.3 項目名一覧（2019年5月）に基づきます。
- 手引きで要素名が空欄の小項目（15.1〜15.2、16.1〜16.8、17.1〜17.3、18.1）は、PMDA が公開している実際の XML で要素名を確認しました（`source: "PMDA-XML"`）。
- 比較画面の「記載のない項目も表示」をオンにすると、選んだどの品目にも記載がない項目も「（記載なし）」として表示します。

## 制限事項・今後の課題

- PMDA の画面構成（検索フォームの項目、結果画面の HTML）に依存しています。PMDA 側の変更で動かなくなる可能性があります。
- 対象は新記載要領の XML 添付文書のみです。XML のない品目（旧記載要領など）は検索結果に表示しません。
- 「12 臨床検査結果に及ぼす影響」（`InfluenceOnLaboratoryValues`）と「25 保険給付上の注意」（`AttentionOfInsurance`）は、
  手引きの要素名をもとに登録しています。実際の XML ではまだ確認していません。
- 項目マスタにない要素が XML にあった場合は、XML 上の位置に要素名のまま表示します。
- 規制区分は XML にコードのみ収載されているため、コードを表示しています。
- 検索結果は 1 ページ 100 件です。
